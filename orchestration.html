Architecture Overview

The architecture is the interface

The system separates source material, orchestration, decision making, execution, outputs, shared memory, and human approval. Each layer has a distinct job and evidence status.

01

Human / UX Designer

Provides evidence, direction, review, and approval.

02

Input Layer

Immutable human source material in input/.

03

Global Orchestration

AGENTS.md governs routing, gates, and system-wide rules.

04

Agent Layer

Decides what happens, when, and which skill is appropriate.

05

Skill Layer

Executes bounded UX tasks using task-specific instructions.

06

Output Layer

Stores derived, versioned UX artifacts by lifecycle stage.

07

Project Memory

Maintains state, questions, assumptions, evidence links, and decisions.

08

Human Approval

Controls progression, revision, and the next handoff.

Operating Model

Agent decides. Skill executes.

The separation protects scope: orchestration stays adaptive while each reusable task retains a clear method, input contract, output, and guardrails.

Agent

  • Decides what needs to happen

  • Selects the appropriate skill
  • Checks prerequisites and evidence
  • Validates output quality
  • Routes work, review, or recovery

  • Defines how a bounded task is performed
  • Identifies required inputs

Guardrails

Reliability is designed in

The shared standards protect the system from plausible but unsupported UX work.

01

Evidence Over Invention

Never fabricate research, participants, requirements, behavior, technical capability, or validation.

02

Assumptions Stay Assumptions

Confidence and repetition do not silently convert an unvalidated premise into fact.

03

Preserve Contradictions

Conflicting evidence remains visible until explicit authority or clarification resolves it.

04

Maintain Traceability

Important artifacts preserve supported upstream and downstream relationships.

05

Human Approval

File creation and quality review never silently satisfy a human gate.

06

Respect Boundaries

Agents route work instead of absorbing another stage’s responsibility.

07

Input Immutability

Original human source files remain unchanged and are never overwritten by generated work.

08

Skip Unsupported Artifacts

The system records gaps rather than manufacturing personas, journeys, findings, or solutions.
